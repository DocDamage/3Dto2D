# Start here

Launch SpriteForge Studio from the package root:

```text
START_HERE.bat
```

## The simplest path

1. Open **Home**.
2. Select **Start creating** and follow the four-step character wizard.
3. Choose a few moves, check readiness, and create your character.
4. Open **Review** to check motion and apply friendly repairs when needed.
5. Open **Export** to package the reviewed character for your game.

You can choose **Try a demo** on Home at any time. It opens the included
playable demo character and does not require a GPU or local model setup.

If you need AI generation, open **Settings** first. SpriteForge will explain
what is ready, what needs attention, and when it can start the local creation
engine automatically.

For detailed steps, use `docs/END_USER_GUIDE.md`. For setup help, use
`docs/FIRST_RUN_CHECKLIST_v8.md` and `docs/TROUBLESHOOTING_v8.md`.
